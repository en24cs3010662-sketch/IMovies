# 🎬 iMovies - Movie Ticket Booking Platform

iMovies is a full-stack MERN web application designed for seamless cinema ticket booking, real-time seat management, and admin show/theatre controls.

## 🚀 Features
- **User Authentication**: Secure JWT-based Registration & Login.
- **Movie Browsing**: Filter blockbusters by genres and release dates.
- **Seat Management**: Interactive seat map selection (Balcony, Middle, Lower).
- **Admin Dashboard**: Management interface to Add Movies, Add Theatres, and Schedule Shows.

## 🛠️ Tech Stack
- **Frontend**: React.js, Tailwind CSS
- **Backend**: Node.js, Express.js
- **Database**: MongoDB
